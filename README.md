# NoteBuns — запасное зеркало раздачи

Автоматический снимок `download.inflexus.world/cloud` для лаунчера NoteBuns.
Рабочий источник — раздача; сюда лаунчер приходит, только если она не ответила.

- Обновляется само с Relay 146 (`gh_mirror_sync.py`), когда на раздаче меняется
  состав файлов. **Руками не править** — следующий снимок всё перезапишет.
- История не хранится: каждый снимок — один коммит.
- Большие архивы (`assets`, `libraries`) лежат частями по ~80 МиБ: у GitHub
  предел 100 МиБ на файл. Лаунчер распаковывает части туда же, куда и целый архив.
- Запасной индекс для лаунчера — в `melody-launcher-minecraft/cloud/index_v3.json`.
